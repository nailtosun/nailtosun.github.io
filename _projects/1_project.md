Industrial partner: [Dyson](https://research.ncl.ac.uk/electric-propulsion/)

Tools: Altium, PLECS, SPICE, MATLAB/Simulink, C2000 MCUs.

This project focuses on current source inverter (CSI) drive solutions for ultra-high-speed electrical machines. Work includes GaN and bidirectional GaN CSI hardware, board design, switching-loss evaluation, and C2000 MCU software development using TMS320F2837xD devices.

Key activities include high-speed machine loss analysis, experimental validation with 100 krpm motors, modulation strategies for gate-driver constraints and common-mode voltage generation, passive component loss evaluation, sensorless motor-control development, and CSI/VSI topology comparisons using virtual prototypes.
