Program: TUBITAK 1004

Tools: COMSOL Multiphysics, MATLAB.

This project used optimization algorithms to design inductors for DC-DC converters and developed pulse-width modulation loss models. Coupled thermal-electromagnetic finite element computations were used to improve converter design decisions.
